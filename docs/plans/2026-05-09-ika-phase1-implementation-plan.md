# Phase 1 — Ika dWallet Custody Replacing FROST: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:executing-plans` to implement this plan task-by-task. Subagents in this project are plan-only; the main agent executes. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the entire FROST custody subsystem with Ika dWallet-controlled BTC custody. By the end of this plan, BTC deposits land at an Ika-controlled P2TR address; redemptions are signed by Ika; `frost_server/` is decommissioned behind a feature flag, then deleted.

**Architecture:** The on-chain `privacy-coin` program continues to gate redemptions with the same `request_redemption` / `complete_redemption` flow it uses today. The off-chain `redemption` worker swaps its `FrostSigner` for an `IkaSigner` that drives a Sui-side Ika dWallet via `@ika.xyz/sdk` (Solana-native Ika is in flight; the off-chain orchestrator pattern matches existing FROST orchestration so the substitution is structural, not architectural). When Ika ships the Solana coordinator program, this same `IkaSigner` interface gets a CPI implementation with no API change to the rest of the system.

**Tech stack:** Rust (Pinocchio program, backend), TypeScript (`@privacy-coin/sdk`, `@ika.xyz/sdk`, web), Bitcoin (testnet, P2TR), Solana devnet, Sui devnet (for the Ika dWallet today; transitions to Solana when Ika's Solana coordinator ships).

**Phase 1 acceptance:** End-to-end test passes — deposit BTC to an Ika-controlled P2TR → SPV-verify on Solana → see shielded note in SDK → transfer privately → request redemption → Ika signs the BTC tx → BTC arrives at withdrawal address. No `frost_server/` process running. Phase 2 (Encrypt swap) is a separate plan written after this one ships.

```typescript
import { payments, networks } from "bitcoinjs-lib";

export type IkaDWalletRef =
  | { type: "literal-pubkey"; pubkey: Buffer }
  | { type: "id"; dwalletId: string };

export function deriveCustodyAddressFromIkaDWallet(
  ref: IkaDWalletRef,
  network: "mainnet" | "testnet" | "regtest"
): string {
  const net =
    network === "mainnet"
      ? networks.bitcoin
      : network === "testnet"
      ? networks.testnet
      : networks.regtest;

  if (ref.type === "literal-pubkey") {
    if (ref.pubkey.length !== 33) {
      throw new Error("Expected 33-byte compressed pubkey");
    }
    const internalPubkey = ref.pubkey.subarray(1); // x-only
    const { address } = payments.p2tr({ internalPubkey, network: net });
    if (!address) throw new Error("p2tr derivation returned no address");
    return address;
  }

  throw new Error(
    "deriveCustodyAddressFromIkaDWallet: 'id' resolution requires Ika SDK; " +
      "use IkaClient (Task 4) to resolve dwalletId → pubkey first"
  );
}
```

Note: this helper is intentionally synchronous and pubkey-only. The `id` branch throws because resolving a dwallet ID to a pubkey requires an async network call to Ika; that resolution lives in the `IkaClient` (Task 4) which then passes the resolved pubkey here.

## Task 4 — IkaClient (TS) and IkaSigner (Rust) plumbing

**Why two layers:** Ika's official SDK is TypeScript. The Rust backend needs an `IkaSigner` that conforms to the same trait as `FrostSigner`. The simplest correct approach: a long-running Node child process (`ika_orchestrator`) hosts the Ika SDK and exposes a small JSON-over-stdin/stdout protocol; `IkaClient` (Rust) is a thin wrapper that pipes signing requests to it. This is the same shape as the FROST HTTP client, just with a different transport.

```typescript
async function main() {
  const client = await IkaClient.init(loadConfigFromEnv());
  const rl = readline.createInterface({ input: process.stdin });
  for await (const line of rl) {
    let req;

    try {

        const sig = await client.sign(req.dwalletId, Buffer.from(req.sighash, "hex"));
        result = { signature: sig.toString("hex") };
      } else if (req.op === "pubkey") {

        result = { pubkey: pk.toString("hex") };
      } else if (req.op === "create_dwallet") {
        const r = await client.createDWallet(req.curve);
        result = { dwalletId: r.dwalletId, pubkey: r.pubkey.toString("hex") };
      } else {
        throw new Error(`unknown op ${req.op}`);
      }
      process.stdout.write(JSON.stringify({ id: req.id, ok: true, result }) + "\n");
    } catch (e: any) {
      process.stdout.write(JSON.stringify({ id: req.id, ok: false, error: String(e?.message || e) }) + "\n");

}
```

```rust
use serde::{Deserialize, Serialize};
use std::process::{Child, Command, Stdio};
use std::sync::Mutex;
use std::io::{BufRead, BufReader, Write};
use uuid::Uuid;

pub struct IkaClient {
    child: Mutex<Child>,
    stdin: Mutex<std::process::ChildStdin>,
    stdout: Mutex<BufReader<std::process::ChildStdout>>,
}

#[derive(Serialize)]
struct Req<'a> {
    id: String,
    op: &'a str,
    #[serde(skip_serializing_if = "Option::is_none")]
    dwallet_id: Option<&'a str>,
    #[serde(skip_serializing_if = "Option::is_none")]
    sighash: Option<&'a str>,
    #[serde(skip_serializing_if = "Option::is_none")]
    curve: Option<&'a str>,
}

#[derive(Deserialize)]
struct Resp {
    id: String,
    ok: bool,
    #[serde(default)]
    result: Option<serde_json::Value>,
    #[serde(default)]
    error: Option<String>,
}

impl IkaClient {
    pub fn spawn(orchestrator_path: &str) -> anyhow::Result<Self> {
        let mut child = Command::new("bun")
            .args(["run", orchestrator_path])
            .stdin(Stdio::piped())
            .stdout(Stdio::piped())
            .stderr(Stdio::inherit())
            .spawn()?;
        let stdin = child.stdin.take().unwrap();
        let stdout = BufReader::new(child.stdout.take().unwrap());
        Ok(Self {
            child: Mutex::new(child),
            stdin: Mutex::new(stdin),
            stdout: Mutex::new(stdout),
        })
    }

    fn rpc(&self, op: &str, dwallet_id: Option<&str>, sighash: Option<&str>, curve: Option<&str>) -> anyhow::Result<serde_json::Value> {
        let id = Uuid::new_v4().to_string();
        let req = Req { id: id.clone(), op, dwallet_id, sighash, curve };
        let line = serde_json::to_string(&req)? + "\n";
        self.stdin.lock().unwrap().write_all(line.as_bytes())?;
        let mut buf = String::new();
        self.stdout.lock().unwrap().read_line(&mut buf)?;
        let resp: Resp = serde_json::from_str(&buf)?;
        if resp.id != id { anyhow::bail!("id mismatch"); }
        if !resp.ok { anyhow::bail!("ika error: {}", resp.error.unwrap_or_default()); }
        Ok(resp.result.unwrap())
    }

    pub fn sign(&self, dwallet_id: &str, sighash: &[u8]) -> anyhow::Result<[u8; 64]> {
        let hex_sh = hex::encode(sighash);
        let r = self.rpc("sign", Some(dwallet_id), Some(&hex_sh), None)?;
        let sig_hex = r["signature"].as_str().ok_or_else(|| anyhow::anyhow!("no signature"))?;
        let sig_bytes = hex::decode(sig_hex)?;
        let mut out = [0u8; 64];
        out.copy_from_slice(&sig_bytes);
        Ok(out)
    }

    pub fn resolve_pubkey(&self, dwallet_id: &str) -> anyhow::Result<[u8; 33]> {
        let r = self.rpc("pubkey", Some(dwallet_id), None, None)?;
        let pk_hex = r["pubkey"].as_str().ok_or_else(|| anyhow::anyhow!("no pubkey"))?;
        let pk = hex::decode(pk_hex)?;
        let mut out = [0u8; 33];
        out.copy_from_slice(&pk);
        Ok(out)
    }
}
```
