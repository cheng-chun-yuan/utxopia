# UTXOpia Monorepo Archive

This repository is archived and no longer used for active development.

UTXOpia has moved to split repositories so public cryptography, programs, SDK, and web code can stay open while backend and operational code can be managed separately.

## Current Repositories

Public:

- https://github.com/UTXOpia/utxopia-sdk
- https://github.com/UTXOpia/utxopia-web
- https://github.com/UTXOpia/utxopia-solana-programs
- https://github.com/UTXOpia/utxopia-sui-programs
- https://github.com/UTXOpia/utxopia-circuits

Restricted:

- https://github.com/UTXOpia/utxopia-backend
- https://github.com/UTXOpia/utxopia-ops

## Status

The split repositories are now the source of truth. Use them for builds, deploys, tests, and demo flows.

This monorepo remains available only for historical reference.
